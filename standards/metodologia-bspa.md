# POP técnico — BSPA Exia para agentes n8n

**Brainstorm:** briefing do cliente, segmento, persona, regras, integrações, histórico e critérios de sucesso.

**Spec:** requisitos, fluxos, states, contratos de API, gatilhos, política de mensagens, erros, limites, módulos opcionais e testes de aceitação.

**Revisão técnica prévia:** Code Review das especificações antes do plano e da implementação.

**Plano:** decompor patches pequenos e reversíveis; versão da base; riscos; checkpoints e backup.

**Implementação:** derivar base por segmento sem sobrescrever originais; adaptar prompt humanizado; instalar e utilizar skills oficiais do n8n; testes locais.

**Auditoria:** Code Review final, regressão, segurança, testes com pin data, integrações reais controladas, observabilidade, persistência e rollback.

**Entrega:** documentação completa de diffs, dependências, testes executados e pendentes. Nenhuma publicação sem autorização.
